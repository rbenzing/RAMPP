# phpMyAdmin Integration Design

**Date:** 2026-05-16
**Status:** Approved

---

## Overview

Add optional phpMyAdmin support to RAMP. A toggle "Admin" button appears on the MySQL service row, enabled only when MySQL + PHP + Apache are all Running and the `phpmyadmin/` directory exists. Toggling on configures phpMyAdmin into the existing Apache instance via a separate include file and opens the browser. State is persisted across restarts.

phpMyAdmin is treated as a **config toggle + browser launch**, not a managed service. No new `Service` enum variant. No new state machine paths. Minimal blast radius.

---

## Architecture

### Approach

Option A: Pure UI + Apache config patch.

- phpMyAdmin files live at `<install>/phpmyadmin/` (user-installed, not bundled by RAMP)
- Apache serves phpMyAdmin via an `Alias` at `/phpmyadmin` on the existing Apache port
- A dedicated `apache/conf/phpmyadmin.conf` is either populated (enabled) or empty (disabled)
- The main `httpd.conf` always includes `phpmyadmin.conf` via an `Include` directive at the bottom
- RAMP generates `phpmyadmin/config.inc.php` (unless user owns it)
- State flows through the existing reducer event loop via `Event::TogglePhpMyAdmin` and `Event::PhpMyAdminToggled(bool)`

### Architectural Law Compliance

The reducer owns `phpmyadmin_enabled` state. The executor performs I/O (writes conf files, opens browser) then emits `Event::PhpMyAdminToggled(bool)` as a follow-up event. The reducer handles that event to update state and emit `SideEffect::PersistDesiredState`.

## State Changes

### `AppState` (runtime)

```rust
pub struct AppState {
    // existing fields ...
    pub phpmyadmin_enabled: bool,
    pub phpmyadmin_dir_exists: bool,  // checked at startup + ConfigReloaded; not persisted
}
```

### `PersistedState`

```rust
pub struct PersistedState {
    // existing fields ...
    #[serde(default)]
    pub phpmyadmin_enabled: bool,
}
```

`#[serde(default)]` ensures old `ramp.state` files (without the field) deserialize cleanly as `false`.

### `RampConfig` / `ramp.toml`

Optional `[phpmyadmin]` section:

```toml
[phpmyadmin]
mysql_user = "root"      # optional, defaults to "root"
mysql_password = ""      # optional, defaults to ""
```

No separate port — phpMyAdmin is served under the existing Apache port at `/phpmyadmin`.

## Apache Config Integration

### `httpd.conf` (always present)

RAMP appends to the generated `httpd.conf`:

```apache
# phpMyAdmin — managed by RAMP (do not remove this line)
Include "conf/phpmyadmin.conf"
```

This line is written by `generate_httpd_conf_with_ports`. The `phpmyadmin.conf` file is always present on disk (created at startup if missing — either empty or populated depending on persisted state).

### `phpmyadmin.conf` when **enabled**

```apache
# RAMP — phpMyAdmin enabled
Alias /phpmyadmin "<install_dir>/phpmyadmin"
<Directory "<install_dir>/phpmyadmin">
    Options None
    AllowOverride None
    Require local
</Directory>

# Route .php files under /phpmyadmin through PHP-CGI FastCGI.
# Uses ProxyPassMatch (not FilesMatch+SetHandler) to avoid the Windows
# mod_proxy_fcgi drive-letter URL parsing bug (same workaround as httpd.conf).
ProxyFCGIBackendType GENERIC
ProxyPassMatch "^/phpmyadmin/(.+\.php(/.*)?)$" "fcgi://127.0.0.1:<php_port>/phpmyadmin/$1"
```

### `phpmyadmin.conf` when **disabled**

Empty file (zero bytes). Apache includes it harmlessly.

## `config.inc.php` Generation

### Ownership detection

If line 2 of `config.inc.php` contains the RAMP marker comment, RAMP owns it and regenerates on toggle-on. If the marker is absent, RAMP never touches the file.

### Credential resolution

1. Use `ramp.toml` `[phpmyadmin]` `mysql_user` / `mysql_password` if present
2. Fall back to `root` / `""` (no password)

### `blowfish_secret`

- Generated once on first toggle-on using `SystemTime::now().duration_since(UNIX_EPOCH).as_nanos()` XOR'd with `std::process::id()`, formatted as hex and truncated/padded to 32 chars
- No external crate required — sufficient for a local dev tool (blowfish_secret only protects session cookie encryption, not user data)
- Stored as `phpmyadmin_blowfish_secret: Option<String>` in `PersistedState` — generated on first toggle-on, reused forever after so sessions survive Apache restarts

### Generated content

```php
<?php
// RAMP — generated config.inc.php (do not remove this line — RAMP uses it to detect generated configs)
$cfg['blowfish_secret'] = '<32-char-secret>';
$cfg['Servers'][1]['auth_type'] = 'config';
$cfg['Servers'][1]['host'] = '127.0.0.1';
$cfg['Servers'][1]['port'] = <mysql_effective_port>;
$cfg['Servers'][1]['user'] = '<mysql_user>';
$cfg['Servers'][1]['password'] = '<mysql_password>';
$cfg['Servers'][1]['AllowNoPassword'] = true;
$cfg['UploadDir'] = '';
$cfg['SaveDir'] = '';
```

## Event Flow

### New events

```rust
Event::TogglePhpMyAdmin       // emitted by UI button click
Event::PhpMyAdminToggled(bool) // emitted by executor after I/O completes
```

### New side effect

```rust
SideEffect::TogglePhpMyAdmin(bool) // produced by reducer, consumed by executor
```

### Toggle-on flow

1. UI sends `Event::TogglePhpMyAdmin`
2. Reducer checks: `phpmyadmin_dir_exists && mysql.state == Running && php.state == Running && apache.state == Running`
   - If preconditions fail → emit `SideEffect::LogEvent(error)`, no state change
   - If ok → emit `SideEffect::TogglePhpMyAdmin(true)`
3. Executor `do_toggle_phpmyadmin(true)`:
   a. Check `phpmyadmin_dir_exists` again — abort with log if missing
   b. Resolve/generate `blowfish_secret`
   c. Write `config.inc.php` (atomic write) — skip if user-owned
   d. Write enabled `phpmyadmin.conf` (atomic write)
   e. Emit `Event::PhpMyAdminToggled(true)` into event queue
   f. Emit `Event::RestartService(Service::Apache)` into event queue
   g. Open browser: `http://127.0.0.1:<apache_effective_port>/phpmyadmin`
4. Reducer handles `Event::PhpMyAdminToggled(true)`:
   - Set `state.phpmyadmin_enabled = true`
   - Emit `SideEffect::PersistDesiredState`

### Toggle-off flow

1. UI sends `Event::TogglePhpMyAdmin`
2. Reducer emits `SideEffect::TogglePhpMyAdmin(false)`
3. Executor:
   a. Write empty `phpmyadmin.conf` (atomic write)
   b. Emit `Event::PhpMyAdminToggled(false)`
   c. Emit `Event::RestartService(Service::Apache)`
4. Reducer handles `Event::PhpMyAdminToggled(false)`:
   - Set `state.phpmyadmin_enabled = false`
   - Emit `SideEffect::PersistDesiredState`

### Auto-disable on service stop

When `Event::ProcessExit { service: Mysql | Php, .. }` arrives and `state.phpmyadmin_enabled == true`:
- Reducer emits `SideEffect::TogglePhpMyAdmin(false)` in addition to normal crash handling
- Executor writes empty `phpmyadmin.conf`, emits `Event::PhpMyAdminToggled(false)`, does NOT restart Apache (it's stopping/crashed)

## Startup Reconciliation

After loading `PersistedState`, before starting services:

1. Check if `phpmyadmin_dir` exists → set `AppState::phpmyadmin_dir_exists`
2. If `phpmyadmin_enabled == true && !phpmyadmin_dir_exists`:
   - Log warning: `"phpMyAdmin enabled in state but not found at <path> — disabling"`
   - Force `phpmyadmin_enabled = false`, persist, write empty `phpmyadmin.conf`
3. If `phpmyadmin_enabled == true && phpmyadmin_dir_exists`:
   - Regenerate `config.inc.php` (if RAMP-owned) with current credentials
   - Write enabled `phpmyadmin.conf`
   - Apache will pick it up on first start — no extra restart needed
4. If `phpmyadmin_enabled == false`:
   - Write empty `phpmyadmin.conf` (idempotent, ensures file always exists)
5. `phpmyadmin.conf` always exists on disk after startup — Apache never hits a missing Include

## UI Changes (`ui.rs`)

### Button placement

In `service_row` for MySQL only, inside the right-to-left button cluster, leftmost of the group (rendered last in RTL = appears leftmost visually):

```
[Stop] [Restart] [Start] [Admin ▶]   ← when disabled (off)
[Stop] [Restart] [Start] [Admin ■]   ← when enabled (on)
```

### Enable condition

```rust
let admin_enabled = svc == Service::Mysql
    && state.mysql.state == ServiceState::Running
    && state.php.state == ServiceState::Running
    && state.apache.state == ServiceState::Running
    && state.phpmyadmin_dir_exists;
```

### Disabled tooltip

- Not all services Running → `"MySQL, PHP, and Apache must all be running to use Admin"`
- Dir missing → `"phpMyAdmin not found at <install>/phpmyadmin/"`

### `service_row` signature change

Pass full `AppState` reference (or relevant fields) to `service_row` so it can check cross-service state for the Admin button condition.

## Error Handling Matrix

| Failure | Action |
|---------|--------|
| `phpmyadmin/` dir missing at toggle | Log error, abort toggle, no state change |
| `config.inc.php` write fails | Log error, abort toggle, no state change |
| `phpmyadmin.conf` write fails | Log error, abort toggle, no state change |
| Apache restart fails after toggle | State already set; Apache will pick up conf on next start |
| `ramp.state` persist fails | Existing persist-failure handling (log error) |
| MySQL/PHP stop while admin enabled | Auto-disable: write empty conf, persist false, no Apache restart |
| `phpmyadmin_dir_exists` false at startup with enabled state | Force disable, persist, log warning |
| User-owned `config.inc.php` | Detect by marker absence, never overwrite |

## Testing

### Layer 1 — Pure reducer tests

- `TogglePhpMyAdmin` when preconditions met → produces `SideEffect::TogglePhpMyAdmin(true/false)`
- `TogglePhpMyAdmin` when MySQL not Running → no state change, LogEvent
- `PhpMyAdminToggled(true/false)` → updates `phpmyadmin_enabled`, produces `PersistDesiredState`
- `ProcessExit(Mysql)` while `phpmyadmin_enabled` → produces `SideEffect::TogglePhpMyAdmin(false)` + normal crash effects
- `ProcessExit(Php)` while `phpmyadmin_enabled` → same

### Layer 2 — `phpmyadmin_conf.rs` unit tests

- `generate_phpmyadmin_apache_conf` contains correct `Alias` and `Directory` paths
- `generate_config_inc_php` contains correct host/port/user/password
- RAMP marker detection: present → owned, absent → not owned
- Credential fallback: no toml section → root/empty
- Credential override: toml section present → uses configured values

### Layer 3 — Integration

- Toggle-on with all services running → `phpmyadmin.conf` populated, `config.inc.php` written
- Toggle-off → `phpmyadmin.conf` empty
- Startup with `phpmyadmin_enabled=true` and dir missing → disabled, persisted false
- Old `ramp.state` without `phpmyadmin_enabled` field → deserializes as false
